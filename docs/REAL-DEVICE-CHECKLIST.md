# Real-device checklist (about ten minutes per phone)

The automated test runs in an emulator. These things only show up on a real phone. The same list is in the app under Guide, Test this phone.

1. **Install.** Open the live link in Safari, Share (or the three dots), Add to Home Screen, and check the name says "Rens Training". Open it from the Home Screen.
2. **Version.** Guide, About this phone: note the build number. Tap Check for an update.
3. **Sounds and voice.** Guide, Test this phone: tap Try on Sounds and Voice with the ringer on. (iPhones do not vibrate for web apps.)
4. **Share sheet.** Tap Try on Share sheet, then Share code and Share weekly report.
5. **Calendar file.** Week, Add the plan to my calendar, and add it to Calendar.
6. **Reminder.** Allow notifications and tap Try on Reminder notification (Home Screen app only).
7. **Two-phone sync.** Create a family code on Tristan's phone. On the other phone, join by typing, by Share code, and by Scan the QR code. Check the "Who is using this phone?" question, then check a block on Tristan's phone and watch it appear on the other.
8. **Family view.** On the parent phone, check that tapping blocks does not log anything.
9. **Text size and layout.** Try Normal, Large and Larger on every tab, in portrait and landscape. Nothing should be cut off, and nothing should scroll sideways. On the 17 Pro Max also check the area around the Dynamic Island and the home bar.
10. **Film a drill and Compare.** Film a short clip, then Compare clips with a second clip. Try a YouTube link too.
11. **Dark mode.** Switch the phone to dark mode and look at Today, Log and Guide.
12. **If anything is wrong:** Guide, Send diagnostics, and send the text to Claude.
